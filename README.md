# Brownies da Soso

Cardápio digital desenvolvido como projeto de curso. A página reúne produtos,
filtros, animações de corte e um resumo de encomenda montado no navegador.

## Abrir o site

A [demonstração no portfólio](https://guirab.com.br/demos/brownies/index.html)
usa um pedido fixo, sem coletar dados ou enviar encomendas.

Para executar esta versão localmente, sirva a pasta por HTTP, por exemplo com
`npx serve .`. Os arquivos principais são `index.html`, `estilo.css` e
`script.js`. A seleção do cardápio é salva apenas no navegador.

`main.html` preserva a primeira versão do exercício.

## Tecnologias

HTML, CSS e JavaScript, sem framework. Fontes Fraunces e Karla pelo Google Fonts.
